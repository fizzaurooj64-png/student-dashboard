# Student Dashboard 📚

A minimal and aesthetic Student Dashboard built using HTML, CSS, and JavaScript.

## ✨ Features
- Student Dashboard interface
- My Subjects section
- Notes management
- Clean and minimal design
- Interactive elements using JavaScript

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enjoy exploring the dashboard!

## 📁 Project Structure

```text
Student-Dashboard/
├── index.html
├── style.css
└── script.js
```
